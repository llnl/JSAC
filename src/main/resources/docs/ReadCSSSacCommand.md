## READCSS

**SUMMARY**

    Changes the values of selected header fields.
****
**SYNTAX**

    READCSS {RCSS} {MORE}  WFDISCFILE {WFILE}  wfdisc filename
****
**INPUT**

    MORE:

    Place the new data files in memory AFTER the old ones. If this option is omitted, the new data files REPLACE the old ones.
