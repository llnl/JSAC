## BORDER


**SUMMARY**

    Controls the plotting of a border around plots.
****

**SYNTAX**
   
    BORDER ON|OFF WIDTH VALUE, BACKGROUND VALUE, SUBPLOT_BORDERS VALUE SUBPLOT_SPACING VALUE
****


**INPUT**

    {ON}:			Turn border plotting on.

    OFF:			Turn border plotting off.

    WIDTH			Border width in mm {Default is 20 mm}

    BACKGROUND   	Color of border {Default is WHITE}

    SUBPLOT_BORDERS Draw box around individual sub-plots {Default is ON}

    SUBPLOT_SPACING Vertical spacing between sub-plots in mm {Default is 0}
****

**DEFAULT VALUES**

    BORDER OFF,
    WIDTH 20,
    BACKGROUND WHITE,
    SUBPLOT_BORDERS ON,
    SUBPLOT_SPACING 0
