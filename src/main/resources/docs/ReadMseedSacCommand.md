## READMSEED    

**SUMMARY**

    Read data files in miniSEED format from disk into memory.
****
**SYNTAX**

    READMSEED {MORE} {DIR name} filelist
****
**INPUT**

    MORE:

    See the READ command.

    DIR name:

    The directory to be searched for miniSEED file(s).
    filelist:

    The name(s) of one or more miniSEED files.
