## PLOT


**SUMMARY**

    Generates a single-trace single-window plot.
****


**SYNTAX**

    PLOT {PRINT}
****

**DESCRIPTION**

    Each data file is displayed one at a time in a single plot window. After each file is plotted the prompt PLOT (Q to quit plotting) is displayed. To advance to the next plot press the Enter key. 

    To quit plotting press the Q key.

    Note: If output was requested all plots are processed without interaction.
