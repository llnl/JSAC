## AGENCY

**SUMMARY**

    This command will set the agency of each data file in memory. The agency may be the same or different for each data file. If there are more data files in memory than agencies, then the last agency entered is used for the remainder of the data files in memory. To unset all agencies execute the command with no arguments. To unset the agency for a specific file enter the agency name as --.
****
**SYNTAX**

    AGENCY {v1 {v2 ... vn} }
****
**INPUT**

    v1:	Agency for first file.

    v2:	Agency for second file.

    vn:	Agency for nth file.
****

**DEFAULT VALUES**

    AGENCY NULL
