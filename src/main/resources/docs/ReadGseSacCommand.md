## READGSE

**SUMMARY**

    Read data files in GSE 2.0 format from disk into memory.

**SYNTAX**

    READGSE {MORE} {DIR name} filelist

**INPUT**

    MORE:

    See the READ command

    DIR name:

    The directory to be searched for gse file(s).

    filelist:

    The name(s) of one or more gse files.
