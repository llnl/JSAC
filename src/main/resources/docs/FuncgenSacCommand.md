## FUNCGEN  

**SUMMARY**

    Generates a function and stores it in memory.
****

**SYNTAX**

    FUNCGEN {type},{DELTA v},{NPTS n},{BEGIN v}

    where type is one of the following:

    IMPULSE

    STEP

    BOXCAR

    TRIANGLE

    SINE {frequency phase}

    LINE {slope intercept}

    QUADRATIC {a b c}

    CUBIC {a b c d}

    SEISMOGRAM
